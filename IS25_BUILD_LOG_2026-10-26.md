## 1. Code changes

Exactly two files were edited in `INF2004-main/`. Nothing else was modified.

### 1.1 Left encoder moved to Grove 1 — `app_program/subsystem2/subsystem2.h:35`

```diff
  #define S2_PIN_MOT_L_A         8u      /* M1A, PWM slice 4A. */
  #define S2_PIN_MOT_L_B         9u      /* M1B, PWM slice 4B. */
  #define S2_PIN_MOT_R_A         10u     /* M2A, PWM slice 5A. */
  #define S2_PIN_MOT_R_B         11u     /* M2B, PWM slice 5B. */
- #define S2_PIN_ENC_L_A         2u      /* Left encoder phase A (Grove 2).  */
+ #define S2_PIN_ENC_L_A         0u      /* Left encoder phase A (Grove 1).  */
  #define S2_PIN_ENC_R_A         3u      /* Right encoder phase A (Grove 2). */
  #define S2_PIN_ENC_L_B         6u      /* Phase B fallback (not wired yet). */
  #define S2_PIN_ENC_R_B         7u      /* Phase B fallback (not wired yet). */
```

**Why.** As written, both encoders were assigned to GP2 + GP3 — the two signal
pins of a single Grove 2 connector. That connector has only **one 3V3 pin and one
GND pin**, so two encoders could only be powered by forcing two wires into one
socket each. Moving the left encoder to Grove 1 / GP0 gives each encoder its own
power pair, at the cost of one digit.

Nothing else in subsystem 2 needed changing: the interrupt attach, counters and
callbacks all reference `S2_PIN_ENC_L_A` symbolically.

**Constraint introduced:** the left encoder no longer exists if the firmware is
built with `CRASH_REPORT=1` (or `CONSOLE=uart`), which assigns UART0 to GP0/GP1.
Default is `CRASH_REPORT=0`, so the normal and test builds are fine.

## 2. Cable colour convention (read this first)

The Grove cables in this kit are **not** in Seeed's standard order:

| Wire | Grove connector pin | Carries |
|---|---|---|
| **white** | pin 1 | signal A — the port's **first** GPIO |
| **yellow** | pin 2 | signal B — the port's **second** GPIO |
| **red** | pin 3 | 3V3 |
| **black** | pin 4 | GND |

Every online Grove tutorial says yellow is signal 1. On this car it is white.
Both the wiring below and any future rewiring depend on this fact.

## 3. Full wiring as it stands tonight

| Device | Connector on the board | Signal pin(s) | Notes |
|---|---|---|---|
| Motor 1 (left) | **M1A / M1B** screw terminal | GP8 / GP9 (via driver) | motor pair = the two thick wires |
| Motor 2 (right) | **M2A / M2B** screw terminal | GP10 / GP11 (via driver) | polarity sets direction; swap pair to reverse |
| Right encoder | **Grove 2** | **GP3** (white) | VCC → red, GND → black; B phase taped |
| Left encoder | **Grove 1** *(pending cable)* | **GP0** (white) | same colours; own 3V3 + GND |
| IR left | **Grove 5** | **GP26** = yellow → **AO** | white (GP6) taped off |
| IR centre | **Grove 6** | **GP27** = yellow → **AO** | white (GP26) taped off |
| IR right / barcode | **Grove 7** | **GP28** = yellow → **AO** | white (GP7) taped off |
| Ultrasonic HC-SR04 | **Grove 3** | **Trig GP4** (white), **Echo GP5** (yellow) | powered from 3V3, so echo swings 3.3 V — **no divider fitted** |
| Servo SG90 | **servo header** | signal **GP15** | V+ = battery voltage, never 3V3 |
| IMU GY-511 | **Grove 4** *(pending cable)* | **SDA GP16** (white), **SCL GP17** (yellow) | mount rigid, X arrow forward |
| Battery | **VIN terminal** | 3.6–6 V | power switch on the board |

Ports now free: **Grove 1** is used only by the left encoder, and no port is left
unassigned. GP1, GP6, GP7, GP12, GP17 (before the IMU), GP20/21 (buttons),
GP18 (NeoPixel), GP22 (buzzer), GP23–25/29 (radio) are not used by these
devices.

### Deviations from the team's written plan

| Item | Team doc said | Car now | Why |
|---|---|---|---|
| Left encoder pin | GP2 (both encoders on Grove 2) | **GP0**, Grove 1 | one Grove port cannot power two encoders |
| Ultrasonic echo divider | 1 kΩ / 2 kΩ fitted | **not fitted** | module is powered from 3V3, so the echo never exceeds 3.3 V. The divider is only required at 5 V |
| IR sensors | analog AO on GP26/27/28 | matches | rewired from digital to analog today |
